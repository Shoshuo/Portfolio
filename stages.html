  • API C# (sync MSSQL/MariaDB/PostgreSQL/Sage) — projet abandonné mi-stage
Apprentissage clé : concevoir et livrer une feature complète — de la BDD à l'UI — seul en production réelle, avec des contraintes RGPD concrètes.

Projet phare
Supervision solaire — Analyse & alertes temps réel

Algorithmes PHP de prédiction de tendances + interface web jQuery avec graphiques interactifs. Notifications sonores déclenchées via AppleScript et module Fibaro domotique.

Contexte

LC-Network développe des applications web, dont son produit phare UbiCaisse. Mission : créer des outils de supervision de panneaux photovoltaïques connectés à un système domotique (Fibaro), avec alertes et visualisation de données. Environnement macOS.

Réalisations
  • Notifications sonores pour panneaux solaires (AppleScript + LUA + PHP)
  • Calcul de moyennes/variances et prédiction de tendances PHP
  • Interface jQuery : historique de production, graphiques & calendrier
  • Login Symfony sécurisé — rôles, permissions, hachage
Apprentissage clé : naviguer entre plusieurs langages (PHP, LUA, AppleScript) dans un écosystème IoT — et comprendre la logique d'une data pipeline de l'acquisition à la visualisation.
